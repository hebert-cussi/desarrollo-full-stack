01 Variables: let y const

URLs, configuración, objetos fijos

Contadores, estado de filtros

03 Arrow Functions
Sintaxis corta para escribir funciones. Heredan el this del entorno donde se definen.
Un parámetro: paréntesis opcional. Una expresión: return implícito. Varias líneas: llaves y return. Devolver objeto: envolver en ( ).
// Función tradicional function greet(name) {   return '¡Hola desde el portafolio de ' + name + '!'; } // Arrow function equivalente const greet = (name) => `¡Hola desde el portafolio de ${name}!`; const sayHi = () => 'Hola'; const double = n => n * 2; const getFullName = (first, last) => {   const full = `${first} ${last}`;   return full.trim(); }; const makeUser = (name) => ({ name, active: true });

03 Template Literals
Cadenas delimitadas con backticks ( ` ).

12 Promesas
Una operación que todavía no termina, pero terminará.
pending
fulfilled ✓ resolve
o
rejected ✗ reject
// Crear una promesa function validateEmail(email) {   return new Promise((resolve, reject) => {     setTimeout(() => {       const valid =         /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);       if (valid) resolve({ ok: true, email });       else reject(new Error('Email inválido'));     }, 500);   }); }
// Consumir con .then() y .catch() validateEmail('hebert@ejemplo.com')   .then(({ email }) => {     console.log(`Email válido: ${email}`);     return fetch(url); // otra promesa   })   .then(res => res.json())   .then(data => console.log(data))   .catch(err => {     console.error(err.message);   });

13 async / await
Azúcar sintáctico sobre las promesas: el código asíncrono se lee como si fuera síncrono.
Con .then()
fetch(url)   .then(res => res.json())   .then(data => {     return fetch(data.nextUrl);   })   .then(res => res.json())   .then(data => console.log(data))   .catch(err => console.error(err));
Con async/await ✓
async function getData() {   const res1 = await fetch(url);   const data1 = await res1.json();   const res2 = await fetch(data1.nextUrl);   const data2 = await res2.json();   console.log(data2); }

14 try / catch / finally

18 Promise.all()
Ejecuta varias promesas en paralelo y espera a que todas terminen.
// PokeAPI: 6 detalles al mismo tiempo const details = await Promise.all(   data.results.map(p => fetchJSON(p.url)) ); // Dashboard: 3 endpoints a la vez const [posts, users, todos] = await Promise.all([   fetchJSON(`${API_BASE}/posts?_limit=1`),   fetchJSON(`${API_BASE}/users?_limit=1`),   fetchJSON(`${API_BASE}/todos?_limit=1`), ]);
Promise.all
Espera todas; si una falla, falla todo
Promise.allSettled
Espera todas y no falla: fulfilled o rejected
Promise.race
La primera que termine, bien o mal
Promise.any
La primera que se resuelva con éxito

Flujo completo del formulario
El formulario de contacto combina todos los conceptos de las sesiones 3 y 4.
01
Usuario escribe
evento input → saveFormDraft() en localStorage
02
Usuario envía

03
Lee los campos
new FormData() → destructuring
04
Valida el email
await validateEmail() → Promise
05
Envía
await fetch POST → event loop
06
Lee la respuesta

07
Avisa
showToast() → DOM + classList
08
Siempre

Para llevarse
const por defecto, let si reasignas, nunca var. Genera HTML con map + template literals + join. Usa textContent para datos del usuario. async/await + try/catch/finally para todo lo asíncrono. Promise.all cuando las peticiones son independientes.
